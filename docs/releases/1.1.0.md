# Windowed 1.1.0 发布说明

## 概览

本次更新重点解决了 `Windowed` 在多任务场景下的使用体验问题：现在可以在一个 App 内打开多个独立窗口，同时修复了网页上传文件无法弹出访达的问题，并补齐了若干与启动、窗口尺寸、History 行为相关的交互优化。

## 主要变更

- 新增：支持单 App 多窗口，`⌘N` 可新建空白窗口
- 新增：启动时恢复上次最后使用的单个页面
- 修复：网页上传文件、上传图片、多文件选择时无法弹出访达的问题
- 优化：History 预设在单窗口/多窗口场景下的打开逻辑
- 优化：为 History 预设增加明确的“新开”按钮
- 优化：空白窗口与新开窗口默认尺寸按屏幕比例自适应
- 优化：Dock 图标固定为默认 `Windowed` 图标，预设图标仅作为列表视觉标识
- 优化：Auto-start / Stop command 输入框改为更稳定的原生 AppKit 命令输入控件
