# Windowed 1.1.0

发布日期：2026-08-17

这一版引入了单 App 多窗口，并补上了网页文件上传相关的缺口。

## 更新内容

- 支持单 App 多窗口，`⌘N` 可新建空白窗口
- 启动时恢复上次最后使用的单个页面
- 修复网页上传文件、图片、多文件选择时无法弹出访达的问题
- 调整 History 预设在单窗口和多窗口场景下的打开逻辑，并增加明确的“新开”按钮
- 空白窗口和新开窗口默认尺寸按屏幕比例自适应
- Dock 图标固定为默认 `Windowed` 图标，预设图标仅用于列表识别
- Auto-start / Stop command 输入框改为更稳定的原生 AppKit 命令输入控件
