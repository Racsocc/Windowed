# Windowed 1.2.0 发布说明

## 概览

本次更新重点放在日常使用体验的打磨上：设置面板现在默认以空白新建态打开，启动时可以恢复上次关闭前的全部已配置窗口，本地服务也会继续按各自条目的启停配置运行。同时，History 容量扩展为 20 条普通项且置顶不限数量，设置窗口高度也重新调整为更顺手的 800。

## 主要变更

- 新增：设置面板默认进入空白新建态，History 编辑按钮单独进入编辑模式
- 新增：启动时恢复上次关闭时的全部已配置窗口
- 优化：恢复窗口后继续按条目自己的 start / stop / stop-on-close 配置管理本地服务
- 优化：History 调整为 20 条普通项，置顶不限数量
- 优化：设置窗口默认高度调整为 800
